01

이용약관

본 약관은 shopping-shorts(이하 "이 앱")를 실행하고 사용하는 것에 대한 조건을 정합니다. 이 앱은 개발자 본인이 로컬 환경에서 개인적으로 사용하기 위해 만든 도구이며, 불특정 다수를 대상으로 한 상업 서비스가 아닙니다.

이용 조건

  • 이 앱은 사용자 본인의 컴퓨터에서만 실행됩니다. 별도의 공개 서버나 앱스토어 배포는 없습니다.
  • 업로드하는 상품 사진에 대한 권리는 사용자 본인에게 있어야 합니다.
  • 생성된 영상 및 문구는 실제와 다를 수 있으며(AI 생성 콘텐츠), 사용 전 반드시 직접 확인해야 합니다.
  • 틱톡 등 외부 플랫폼에 게시하는 콘텐츠는 각 플랫폼의 커뮤니티 가이드라인과 광고/협찬 표시 정책을 따라야 합니다.

책임의 한계

이 앱은 무상으로 제공되는 개인 프로젝트로, 어떠한 형태의 보증도 제공하지 않습니다. 생성된 영상의 정확성, 상업적 성과, 외부 서비스(Higgsfield, 틱톡, 쿠팡 등)의 가용성에 대해 개발자는 책임을 지지 않습니다.

02

서비스 성격

회원가입, 로그인, 결제 기능이 없습니다. 이 앱을 실행하는 사람이 유일한 사용자이며, 앱 자체는 사용자 데이터를 별도 서버에 저장하거나 제3자에게 판매하지 않습니다.

03

개인정보처리방침

이 앱이 실제로 다루는 데이터는 다음과 같습니다.

수집·처리하는 정보

  • 업로드한 상품 사진 — 영상 생성을 위해 AI 서비스(Anthropic Claude, Higgsfield)로 전송됩니다.
  • 입력한 상품명·가격·특징 텍스트 — AI 카피 생성에 사용됩니다.
  • 생성된 영상 파일 — 사용자가 직접 요청할 때만 틱톡 계정으로 전송됩니다.

보관 위치

업로드된 사진과 생성 결과는 사용자 본인의 컴퓨터(uploads/, output/ 폴더)와 연동된 외부 AI 서비스에만 존재합니다. 개발자가 운영하는 별도 데이터베이스나 분석 서버는 없습니다.

제3자 제공

사용자가 직접 요청한 경우에만, 아래 "연동 서비스"에 명시된 업체로 필요한 최소한의 데이터 (사진, 영상, 인증 토큰)가 전달됩니다. 그 외의 목적으로는 어떤 정보도 제3자와 공유하지 않습니다.

이용자 권리

모든 데이터는 사용자 본인의 로컬 컴퓨터에 있으므로, 폴더의 파일을 직접 삭제하거나 각 연동 서비스(틱톡 등)에서 앱 연결을 해제하는 것으로 언제든 데이터 이용을 중단할 수 있습니다.

04

연동 서비스

이 앱은 아래 외부 서비스의 API를 사용하며, 각 서비스는 자체 약관과 개인정보처리방침을 따릅니다.

  • Anthropic Claude — 상품 사진 분석 및 광고 카피 생성
  • Higgsfield — AI 영상 생성
  • TikTok — 사용자가 직접 요청할 때, 생성된 영상을 틱톡 계정으로 업로드
  • 쿠팡 파트너스 — 구매 링크를 제휴 링크로 변환
